# Кодекс Ночи

Рабочая энциклопедия хроники Vampire: The Masquerade 5 (Renegade).

- `index.html` — страница сайта и её код, её и раздаёт GitHub Pages.
- `style.css` — всё оформление сайта.
- `data.js` — все тексты хроники: заметки, справочники, связи.
- `images/` — картинки записей (портреты, карты и т.п.), подключаются
  относительными путями — сюда же кладутся новые файлы.
- `src/` — исходники для пересборки. Собирается командой `bash build.sh`
  из папки `src/`; результат — `index.html`, `style.css` и `data.js`,
  которые копируются в корень репозитория (и `kodeks-nochi.html` — тот
  же сайт одним файлом для офлайна и проверок). Правила для ИИ-агента —
  `src/RULES.md`, журнал изменений — `src/CHANGELOG.md`.

Ссылка на живую страницу: `https://<логин>.github.io/<репозиторий>/`
(включается в Settings → Pages → Source: Deploy from a branch → main → / (root)).
