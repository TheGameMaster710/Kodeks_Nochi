# Кодекс Ночи

Рабочая энциклопедия хроники Vampire: The Masquerade 5 (Renegade).

- `index.html` — готовая страница, её и раздаёт GitHub Pages.
- `images/` — картинки записей (портреты, карты и т.п.), подключаются
  относительными путями из `index.html` — сюда же кладутся новые файлы.
- `src/` — исходники для пересборки `index.html` (см. инструкцию для
  ИИ-агента в самом верху `src/p0_comment.html`). Собирается командой
  `bash build.sh` из папки `src/`, результат — `kodeks-nochi.html`,
  который переименовывается/копируется в `index.html` в корне репозитория.

Ссылка на живую страницу: `https://<логин>.github.io/<репозиторий>/`
(включается в Settings → Pages → Source: Deploy from a branch → main → / (root)).
